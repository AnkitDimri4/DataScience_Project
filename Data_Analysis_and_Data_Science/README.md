#  Data Analysis and Data Science

This repository contains structured learning materials, practical notebooks, datasets, and case studies related to **Data Analysis and Data Science** using Python.

It covers core concepts such as:

* NumPy fundamentals
* Pandas data handling
* Data visualization (Matplotlib & Seaborn)
* Handling missing data
* Real-world dataset analysis
* Case studies and exploratory data analysis (EDA)

## How to Run

1. Install Python (3.x recommended)
2. Install required libraries:

```bash
pip install numpy pandas matplotlib seaborn jupyter
```

3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open any `.ipynb` file and run the cells.
